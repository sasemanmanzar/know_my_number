# Know My Number – Official Website

**Official Website of an Educational Android App for Children**

This website introduces Know My Number, an educational Android application designed to help young children learn and memorize their parents' phone numbers through fun and interactive games.

It provides information about the app, its features, screenshots, and download options.

## ✨ Website Features

- App introduction and overview
- App features and benefits
- Application screenshots
- Download links for Cafe Bazaar and Myket
- Direct APK download
- Privacy policy

## 🛠️ Technologies

- **Frontend:** React.js
- **Language:** JavaScript
- **Markup:** HTML5
- **Styling:** CSS3
- **Design:** Responsive Web Design
